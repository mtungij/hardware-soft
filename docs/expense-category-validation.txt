Root cause
The Volt editor used Rule::unique('expense_categories', 'name') without company_id.
The original migration also created a global name unique index. The subsequent
multi-company migration did not replace this particular index. Eloquent company
scopes do not apply to the validator's raw table queries or database indexes.
HasCompany assigns ordinary staff ownership correctly. ExpenseCategorySeeder
already includes company_id in firstOrCreate; it needed no change.

name, and expense_categories_name_unique(name). It contains 0 categories and
0 expenses; duplicate tenant/name groups and null-owner categories both number 0.
No migration or data writes were performed on that database. Historical data
preservation was instead verified using deliberately populated disposable tables.
